        Profile
        

          Backend by conviction,
          not by accident.
        

      

    


    

      I'm Mohammed Fazil — a backend developer who enjoys the unglamorous half of
      software: the part that has to stay up when the market opens.
    


    

      

        

          At Geojit Technologies I design secure RESTful APIs for enterprise financial platforms serving
          thousands of daily active users, and build Kafka-based microservices that process trades and
          transactions in real time. Redis caching cut database load by 30%; targeted query and
          connection-pool tuning took ~40% off API response times under peak trading hours.
        

        

          I lean on Circuit Breaker, API Gateway and Service Discovery patterns, keep quality gated
          through SonarQube and JUnit, and hold a hard line on SOLID and clean architecture — because
          the code that survives is the code the next person can read.
